Questions & Answers

Frequently Asked Questions

What overhead does the Aurora SDK add to our model inference? ▼
The Aurora SDK transmits spans via asynchronous background workers using HTTP/2 batching. Benchmark overhead is strictly sub-millisecond (<0.4ms) and will never block or introduce latency to user-facing responses.
Is sensitive user data or API keys encrypted during ingestion? ▼
Yes. Aurora features automated local masking: regex and NER rules detect PII (emails, credit cards, SSNs, API tokens) before payloads leave your infrastructure. All data in transit is encrypted via TLS 1.3, and data at rest is encrypted via AES-256-GCM.
Can we self-host Aurora on our own Kubernetes cluster? ▼
Enterprise tier customers receive full Helm charts and Terraform recipes to deploy Aurora in their private AWS, GCP, or Azure VPC, ensuring complete data sovereignty.
How does the semantic prompt caching work? ▼
Incoming prompt embeddings are compared against a low-latency vector cache using cosine similarity thresholds. Identical or near-identical prompts are served directly from cache without hitting downstream LLM provider APIs.
